\section{Rollout Model Comparison}

\subsection{Purpose}

The rollout comparison module evaluates whether physics-embedded state improves
long-horizon droplet trajectory prediction relative to the two previous
Markovian baselines.  The comparison is intentionally aligned: all models are
evaluated on the same validation windows, with the same droplet slot ordering
and the same truth-injection semantics for newly appearing droplets.

\subsection{Models Compared}

The self-contained evaluation bundle lives under \texttt{src/evaluation/}.  It
contains local copies of the old comparison pipeline, the attention model class,
geometry-admissibility helpers, centerline/mask data, and the exact checkpoints
used for evaluation.

\begin{longtable}{@{}lll@{}}
\toprule
Label & Input state & Checkpoint \\
\midrule
Geometry-naive Markovian & 5 features &
\texttt{src/evaluation/models/geometry\_naive\_markovian/markovian\_rollout\_transformer\_best.pt} \\
Geometry-aware Markovian & 5 features &
\texttt{src/evaluation/models/geometry\_aware\_markovian/geometry\_aware\_markovian\_rollout\_best.pt} \\
Physics-embedded Markovian & 15 features &
\texttt{src/evaluation/models/physics\_embedded\_markovian/physics\_markovian\_v1\_best\_checkpoint.pt} \\
\bottomrule
\end{longtable}

The two previous baselines consume only:

\[
(x,y,v_x,v_y,\mathrm{circularity}).
\]

The physics-embedded model consumes the full 15-feature state described in the
previous section.  All three models predict only \((v_x,v_y)\).

\subsection{Rollout Semantics}

For each model, predicted velocity is integrated autoregressively:

\[
\hat{\mathbf{x}}_{k+1}
=
\hat{\mathbf{x}}_k
+
\hat{\mathbf{v}}_k.
\]

The comparison preserves the original rollout framework:

\begin{itemize}
  \item identical validation rollout starts for all models;
  \item identical selected droplet slots for all models;
  \item truth injection only for newly appearing droplets;
  \item no future target velocity or position as model input;
  \item 50-step rollout horizon;
  \item 1000 bootstrap replicates for confidence intervals.
\end{itemize}

For old models, the evaluator slices the current canonical state down to the
first five physical/tracking features.  For the physics model, it passes the
full 15-feature tensor and uses the same non-target feature refresh rule as the
physics attention visualizer.

\subsection{Metrics}

The comparison reports:

\begin{itemize}
  \item per-step position RMSE;
  \item per-step velocity RMSE;
  \item integrated position RMSE over the rollout;
  \item final-step position RMSE;
  \item tangential and normal error relative to the centerline tangent basis;
  \item channel footprint outside-fraction and violation rates;
  \item trajectory-level geometry-violation statistics;
  \item junction branch-decision outcomes.
\end{itemize}

Directional decomposition projects position or velocity error onto the local
centerline basis:

\[
e_\parallel = \mathbf{e}\cdot\mathbf{t},
\qquad
e_\perp = \mathbf{e}\cdot\mathbf{n},
\]

where \(\mathbf{t}\) is the local tangent and \(\mathbf{n}\) is the local
normal.  Channel admissibility uses the droplet bounding ellipse and reports
the fraction of its footprint outside the binary channel mask.

\subsection{Execution}

The completed local resume command was:

\begin{verbatim}
python -m src.evaluation.rollout_comparison \
  --predictions-path src/evaluation/outputs/outputs/rollout_model_comparison/rollout_predictions.npz \
  --output-dir src/evaluation/outputs/rollout_model_comparison \
  --cpu
\end{verbatim}
